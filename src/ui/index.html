Get the missing chunks from Minecraft

These chunks were never saved, so only the game can make their real terrain. The exporter can put a small helper into this world that loads every one of them for you.

  1. Open this world in Minecraft. If it is already open, Save & Quit and open it again.
  2. Stay where you are. Progress shows above the hotbar: Exporter: loading missing chunks.
  3. When chat says Done, Save & Quit, then click Reload world here.
Or do it by hand with commands
  1. Open this world in Minecraft with cheats on, in the same dimension.
  2. Run the add commands below in chat, one line at a time.
  3. Wait about 15 seconds, then Save & Quit.
  4. Back here, click Reload world.
  5. Next time you play, run the remove lines to tidy up.
