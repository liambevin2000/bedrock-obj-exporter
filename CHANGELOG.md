# Changelog

## 1.0.3 - 2026-10-20

- Chunk helper: warns when Minecraft was already running before the helper was added and needs a restart to see it.

## 1.0.2 - 2026-10-20

- The Cinema 4D plugin now goes in its own folder, and the extra loose copy that could hide other plugins is removed.

## 1.0.1 - 2026-10-20

- Fixed textures turning into the purple missing-texture pattern after reloading a world several times.
- Missing chunks: one click adds a helper to the world that loads them all next time you open it in Minecraft.

## 1.0.0 - 2026-10-10

- First shared version.
- Pick an area on the map, preview it in 3D, export to OBJ or Cinema 4D.
- Updates itself from GitHub from now on.
